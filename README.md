# R2 Spotter

A static site that shows real owner photos of the Rivian R2, filtered by configuration.

- **Exterior search:** paint + wheels
- **Interior search:** interior color scheme

Photos come from r/RivianR2 and the Rivian forums. The site serves its own copy of each photo, links to the original post and credits the poster.
The site is plain HTML/JS with no build step, so it can be hosted free on GitHub Pages.

## Layout

| Path | What it is |
| --- | --- |
| `index.html`, `style.css`, `app.js` | The site. Loads the two JSON files below and filters in the browser. |
| `data/options.json` | Paint, interior and wheel options. Used by both the site and the tagger. |
| `data/images.json` | Tagged photos (generated by `tools/tag.py`). |
| `data/raw/posts.jsonl` | Collected posts waiting to be tagged (generated by the fetch scripts). |
| `assets/photos/` | Copies of every R2 photo (1024px JPEG), so the site never depends on Reddit or the forum allowing embeds. |
| `tools/` | Scripts you run by hand to collect and tag new photos. |

## Adding new photos (manual)

```sh
pip install -r tools/requirements.txt

# 1. Collect image posts (no Reddit API: uses a public archive + old.reddit pages)
python tools/fetch_reddit.py --since 2026-09-01
python tools/fetch_forum.py --pages 2   # R2 forum + subforums on rivianforums.com

# 2. Tag them with OpenAI's Decisions API (only untagged images are sent).
#    Needs OPENAI_API_KEY=sk-... in the .env file next to this README.
python tools/tag.py --limit 20   # try a few first
python tools/tag.py

# 3. Upload changes to GitHub (no git needed; one-time token setup is at the top of tools/publish.py)
python tools/publish.py
```

## How tagging works

For every image, `tools/tag.py` sends the photo (shrunk to 1024px, as base64) plus the post's
title and text to `POST /v1/decisions` with model `gpt-6-luna`, asking:

- `is_r2` (predicate): is this an R2?
- `view` (choice): exterior, interior, detail or other
- `paint`, `interior`, `wheels` (choice): one of the options in `data/options.json`, or `unknown`

The site only uses tags with confidence of 0.6 or more (`MIN_TAG` in `app.js`). An exterior search shows
exact matches first, then partial matches where the photo agrees on what's visible (for example the
right paint but wheels out of frame).
